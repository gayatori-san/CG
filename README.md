# Data Structures Practicals 1–9

Simplest revision programs for S.Y. B.Tech IT, Semester III.

## Language allocation
- Practicals 1–4: C++
- Practicals 5–9: Python

## Run C++ programs
```bash
g++ practicals/01_templates_containers.cpp -o practical1
./practical1
```
Change the source filename and output name for Practicals 2–4.

## Run Python programs
```bash
python3 practicals/05_expression_tree.py
```
Change the filename for Practicals 6–9.

## Notes
These are deliberately short fixed-data revision examples. Some advanced operations listed in the full syllabus are not included. Practical 3 uses single-digit operands and basic arithmetic; Practical 5 builds from a fixed postfix expression.
